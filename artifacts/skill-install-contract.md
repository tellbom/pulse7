## 行为

pulse7 只从以下两个根目录发现技能，每个完整技能包是根目录的直接子目录：

- 工作区：`<workspace>/.pulse7/skills/<package>/SKILL.md`。
- 全局：`<pulse7运行用户的主目录>/.pulse7/skills/<package>/SKILL.md`。

安装根目录由 `skillRoots` 统一生成，扫描器与模型安装指引共用。目录名由发布方决定，不要求某个社区前缀；名称、简介读取 SKILL.md 元数据。仅有这两层，不新增会话级技能。

每次用户任务开始时生成独立 system 安装指引，包含两个实际根目录。目录为空时同样存在；恢复会话或切换工作区后会替换旧指引，不重复叠加。该固定运行指引计入既有整体上下文预算，不占技能目录的 `skill_catalog_budget_bytes` 配额；原目录预算、压缩阈值、usage 独立性不变。

指引与下载工具、registry、包名无关，要求模型：

1. 遵循用户指定的全局/工作区范围；未指定时使用工作区并说明。
2. 查看所用下载工具支持的目标目录选项，不臆造参数；不支持指定目标时，下载后复制完整技能包到正确根目录，保留脚本、引用文件和资产的相对结构。
3. 在报告安装完成前验证实际落点，读取 SKILL.md 检查当前解析器支持的 frontmatter 与非空单行 name/description，并检查附带资源；格式不合规应如实报告，不静默改写发布方指令。
4. 安装到已有目录或出现同名技能时明确处理冲突；工作区同名优先于全局，不能把被遮蔽的技能称为当前有效技能。
5. 区分“已下载”“已安装并核验”“已发现”“已读取使用”。目录外下载不属于已安装；任务中途安装要等下一任务边界进入目录，当前任务有需要可直接 read 正文，但读取不等于注册。

代码强制的是**发现/注册范围**。安装工作流与完成报告要求通过模型指引表达，不宣称能约束任意第三方下载器或保证所有模型都遵循指令。没有全盘扫描普通 `skills` 目录，没有自动搬动用户的已有文件，没有新增上传接口或专用下载器。

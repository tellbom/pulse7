# 项目整理说明

## 概述
对原始零散文件进行整理，形成结构清晰、可维护的小项目。

## 原始文件
| 文件 | 说明 |
|------|------|
| `TASK.md` | 任务描述 |
| `notes.txt` | 随手记（费用记录） |
| `old_tmp.py` | 临时测试脚本 |

## 整理后结构
```
.
├── README.md        # 项目说明
├── TASK.md          # 原始任务描述
├── notes/           # 笔记/记录
│   ├── expenses.md  # 费用记录（整理后）
│   └── README.md    # 笔记说明
├── src/             # 源代码
│   └── expenses.py  # 费用计算脚本
├── logs/            # 日志文件
│   └── run.log      # 运行日志
└── Makefile         # 常用命令
```

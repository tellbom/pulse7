## 逐项改动

### T1 —— `--resume` 修补未配对 tool_call（commit 104fc1e）
`session.go` 新增 `pairToolCalls`：`loadSession` 载入后按 `call_id` 比对，对每个未应答的 tool_call 在其 assistant 消息之后立即补一条合成 `tool` 消息（固定中文提示：先用只读工具核实、重试须征得用户同意）。不做窗口判定、不自动重跑。
**验收**：构造尾部含未配对 `call-x1` 的 session → `--resume` 输出 `patched 1 interrupted tool call(s)`，续跑正常无消息序列错误。✅

### T2 —— checkpoint 跨会话可发现（commit b4468fa）
`gittools.go` 新增 `refs()`（`git for-each-ref refs/win7-agent/checkpoints/`），`Rollback` 目标解析改为扫描结果（`args.to` 精确匹配 / 缺省取最新 ref），内存 seq 仅用于命名新 checkpoint。回滚结果消息带可用计数。
**验收**：会话 A `M2-GIT` 建 checkpoint → 会话 B（全新 taskID）`T2-ROLLBACK` 成功回滚到 `refs/win7-agent/checkpoints/t0905-014947-101/1`。✅

### T3 —— shell 禁 git 写操作（commit b120b7f，含触发器修正 commit）
`tools.go` 新增 `gitWriteBlocked`：命令按 `& | 换行` 切分后分词，跳过全局参数（`-c/-C/--git-dir/--work-tree/--namespace` 及任意 `-` 前缀项）取子命令，命中 `commit/push/reset/checkout/merge/rebase/cherry-pick/clean/stash` 即拒绝，返回明确中文提示（转交用户执行）。只读子命令放行。
**验收**：`git status` 放行（exitcode=0 真实输出）；`git commit -m x`、`git -C ws5 commit -m x`、`git --git-dir=.git push origin main` 三种形式全部拦截且提示含被拦截子命令。✅

### T4 —— 任务结束摘要 + 轮次上限告警（commit 190613d）
`main.go` 定义 `errMaxRounds` 哨兵（`streamTurn` 撞 8 轮上限返回）；`session.go` 新增 `endOfTaskSummary`：任务结束从 `audit.jsonl` 按 taskID 过滤 shell 调用并打印编号清单（命令+时间）+"外部影响不可回退"提示；命中上限时追加醒目警告行。
**验收**：`T4-NORM`（含一次 shell）正常结束打印完整摘要块；`T4-MAX`（mock 永不给终答）触发 `[警告] 本次任务达到最大轮次上限后停止...`。✅

### T5 —— 清理 `index-*.tmp`（commit 773b4ff）
`cleanup.go` 新增 `purgeStaleIndexTemps`，挂在既有启动清理点（`setupEnv`），清理 `data\sessions\index-*.tmp` 中 mtime >1h 者；新鲜文件保留。
**验收**：伪造 2020 年的 `index-t0101-...tmp` 启动后被清除；当天创建的 `index-t9900-...tmp` 保留。✅

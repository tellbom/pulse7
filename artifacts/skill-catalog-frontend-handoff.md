## 配置字段

沿用 GET /api/config 与 PUT /api/config，新增：

```json
{"skill_catalog_budget_bytes": 8192}
```

| 项目 | 契约 |
|---|---|
| 类型 | 整数 |
| 默认值 | 8192（8 KiB） |
| API 范围 | 1024–1048576，越界或类型错误返回 400 |
| 保存 | 写当前用户全局配置；省略字段保持原值，不写项目配置 |
| 生效 | 空闲时保存，下一次用户任务使用新预算；无需重启 |
| 活动任务中保存 | 沿用现有 409 busy，不排队修改 |
| CLI | --skill-catalog-budget-bytes |
| 总体窗口 | max_ctx 不变；技能目录计入整体窗口，不额外扩大窗口 |

建议标签：**技能目录预算（KiB）**。界面显示 KiB，提交时乘 1024，提交结果必须为整数。提示文字：

> 控制技能名称、简介与定位信息占用的上下文。默认 8 KiB；超限先缩短简介，再省略简介，必要时改为按需查阅完整目录。技能正文仅在模型读取时进入上下文。此值不扩大总上下文窗口。

统计单位是该目录 system 消息 JSON 序列化后的 UTF-8 字节，包含转义与消息包装；不是实际 token。若展示 bytes/4，必须标为估算。现有整体窗口和压缩阈值没有改动，也不读取 usage 或猜测模型规格。

允许用户选择较大预算，但它仍占用 max_ctx；过大的保留内容会被既有整体上下文保护拒绝，不能宣称提高目录预算即可扩大模型窗口。

## 模型能看到什么

正常目录包含 name、description、path、scope，不包含 SKILL.md 正文。后端保留完整描述，取消发现阶段的 200 rune 裁剪和前 20 项限制。

降级顺序为 full → shortened → names → index：

- full：完整元数据。
- shortened：给描述统一的字节额度，UTF-8 安全截断并加省略号，不由代码推测相关性。
- names：保留名称、路径和作用域，description 为空；明确告知描述因预算省略。
- index：目录本身过大，只注入数量及完整元数据索引的路径，模型可使用已有 read 分页或 grep；索引每行一个技能，包含完整描述，不包含正文。

降级时索引存储在 `<数据根>/data/skill-catalogs/<元数据SHA256>.jsonl`，不写工作区，正文仍需 read 对应 SKILL.md。这里“正文按需加载”是指进入模型上下文；发现过程仍沿用读取 SKILL.md 文件并解析 frontmatter 的实现，不声称发现阶段零正文 IO。

## 作用域及刷新

只有两层：`workspace`（工作区/.pulse7/skills）与 `global`（当前运行用户/.pulse7/skills）。同名工作区技能优先于全局技能，并报告覆盖警告；同一来源的重复名称采用稳定目录遍历中的先发现项并告警。

全局不表示跨操作系统用户共享；工作区不表示会话私有。同一工作区的会话共享可发现文件，不共享聊天上下文。

CLI 与 HTTP 在每次用户任务开始、首次模型请求前扫描并重建目录；恢复会话也在下一次任务边界执行。任务内的多轮工具循环不重新扫描、不反复追加目录。外部安装、更新、删除将于下一次任务被发现。

目录是独立带标记的 system 消息；旧目录区块会被替换，历史用户消息、工具结果及已读技能正文不重写。支持旧版本追加在 base system 末尾的标准目录格式迁移。压缩仍沿用原有 system 保留策略。

**本轮没有 watcher、即时更新通知或待刷新标志**，因此前端不能声称已经实时检测到外部文件变化。无需等到新建会话，下一次任务边界会重新扫描。历史会话文件不改写为“当时就用了新版”；重建是当前请求投影。

## SSE 可见性

新增 `skill_catalog`，在每次任务目录构建成功后发出，沿用现有 SSE 信封与会话关联：

```json
{
  "version": "元数据内容的SHA256",
  "mode": "shortened",
  "count": 25,
  "budgetBytes": 8192,
  "listingBytes": 7900,
  "indexPath": "C:\\...\\data\\skill-catalogs\\hash.jsonl",
  "warnings": []
}
```

`mode` 还包括 full、names、index、empty。empty 时 count/listingBytes 为 0；indexPath 可省略；warnings 当前可能为 null，前端按 `warnings ?? []` 处理。version 标识元数据版本，不代表正文版本，也不代表技能已经被使用。改变预算可能只改变 mode/listingBytes，不改变 version。

可展示“本次任务发现 N 个技能 / 目录占用 X KiB / 描述已缩短”等状态。已有 `session_init.skills` 是发现元数据，不等于预算裁剪后的模型目录；已有 `skill_loaded` 表示读取技能的事件，不能与 `skill_catalog` 混为“已经使用”。

目录索引无法写入或最小索引引用仍超过预算时，当前任务显式报错，不静默宣称全部可发现。

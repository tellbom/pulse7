- 计划模式是 pulse7 工具层约束，不是操作系统沙盒。已启动后台进程、外部程序不受其阻止；没有为了阶段化改变 JobObject 或 Sandboxie。
- shell 无可靠只读分类能力，计划模式内整体不可用。读取由现有专用工具完成；需要命令执行时先保存计划退出。没有用字符串白名单猜测命令安全性。
- 模式在 `manifest-<会话>.jsonl.plan.jsonl` 留追加记录。损坏时写操作明确失败而读取仍可用；不会悄悄回退为普通模式。需保全文件后修复该记录，或用户选择新会话；本轮不加入自动修复/清理系统。
- “文件存在”仅证明已落盘，既有文件也满足此事实。不能证明笔记充分、已更新或需求已理解，系统不作这些判断。笔记结构不强制，内容允许修订。
- 普通文件版本依据是大小/mtime，外加实际返回页 SHA256；不是整文件内容哈希。lc1 的版本依据为已验证的不可变内容引用。记录页哈希不需要再次读取整个文件。
- `read_observation` 记录有实际内容页的读取。空文件、越界页、非文本提示和失败仍通过原工具审计/结果计数，没有伪造其源码字节区间。离线统计需区分“调用次数”和“实际内容页次数”。
- 回拉返回超过原有外置阈值时，原始会话存储仍可能保存该工具输出附件；micro 的下一次恢复指针会回到原始来源及页范围，不沿新附件层层回拉。没有改写/删除原始会话。
- 当前新增模型工具可经用户自然语言请求触发；没有新增直接用户按钮、模式状态 HTTP 接口或前端状态栏。前端可先沿用现有工具调用/结果展示，不应凭历史某条成功进入事件推断当前模式。
- keepRecent 默认 8、固定本地估算与阈值不变。没有无条件提高阈值、永久保护、自动读封禁或任何业务专用适配。真实模型效果与可选 8/16 对照尚未验证。

- 清理：经用户扩大授权后，已终止核实为旧验证残留的 worker PID 3152（exit 0）。实际测试始终使用独立最新候选、新工作区/会话；未删除历史证据。全量执行时该旧 worker 尚未清理，见报告环境披露。

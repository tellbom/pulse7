| ```

```
ni-hao-win7

========================================

=== EXEC-DONE ===
=== EXIT DONE code=0 2026-09-06T23:21:43+08:00 ===

```

## REPL 实测记录（验收 7）

## 已知取舍（记 findings，未修）

1. **最终回答出现两次**（前缀流式 + 加框重显）：流的"最终性"只有结束后才知道；扣住不发会失去慢网络下"还活着"的反馈。短答案可接受，长答案重复量大——待真实试用反馈定夺。
2. 叙述前缀 `| ` 与 markdown 代码块视觉混叠（样例中 ``` 行也被前缀）。
3. 失败摘要的"输出 N 行"包含 `[sandbox=...]` 尾注行。

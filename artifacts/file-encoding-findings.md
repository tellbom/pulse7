## F-4 `%date%` 中文（周日）经 cmd echo 进日志显示为 FFFD

cmd 的 echo %date% 以 GBK 写日志文件，分析脚本按 UTF-8 读出现替换符。纯台架显示问题，
不影响任何产品链路；后续分析脚本可按 GBK 读或改用纯 ASCII 时间戳。

## F-5 read 分页 + 文件解码的交互：GBK 文件的行数按解码后内容计

readPage 在解码后的字符串上行数统计——GBK 文件的"共 N 行"是解码视角的行数，与字节
级行号一致（GBK 无换行歧义），无正确性问题，仅记录语义。

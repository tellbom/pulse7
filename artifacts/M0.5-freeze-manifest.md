## Gate E 约束与适配要点（M1 已按此实现）

1. **Plus(IFW) 安装器在会话 0 静默安装失败**（/S 与 IFW 参数均挂起）→ 冻结为 **Classic 5.73.2 NSIS /S**（同引擎同仓库）。
2. **未打 SHA-2 补丁的 Win7 无法加载 SbieDrv（sc start 错误 577）**→ 开发机以 KB4474419 解决（需重启一次）；**生产环境禁补丁** → 安装器必须探测驱动可用性，不可用则降级 Job Object 方案（运行时无需管理员）。
3. **Start.exe 只能在用户交互会话运行**（ssh/服务会话内挂起）——与产品形态一致（agent 在用户桌面会话运行）。
4. **非管理员令牌（trustlevel 0x20000）下 Start.exe /wait 正常**（NA-WAIT-EC=0）→ 满足"安装超管、运行普通权限"。
5. **退出码偶数原样透传、奇数变为 0x40010004** → shell 工具用 wrapper 批处理把 exit code 写文件回传。
6. **stdout/stderr 不经控制台转发** → 同一 wrapper 把输出写入 box 内文件，从容器映射路径读取。
7. **文件隔离实证**：box 内写不落真实 FS；`OpenFilePath=<路径>\*` + `Start.exe /reload` 实现工作区直写（R9 PASS）。
8. `delete_sandbox_silent`、`/terminate`、`/listpids`、连续执行稳定性均验证通过。

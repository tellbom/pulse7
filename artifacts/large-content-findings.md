# 大内容处理未完成与限制

2026-09-13。

1. 旧 IP SSH 阻断已由用户提供新 IP 192.168.140.130 解决。amd64 全量 175 项及独立 HTTP 回归已实测通过；测试子代理额度中断不构成测试结果，实际验收由主代理接手。
2. 历史超过 1 MiB 的 JSONL 单行仍不自动迁移；此前隔离文件保留，不删除、不静默跳过恢复。新写入外置不能自动修复旧数据。
3. 附件需要与会话一起备份和迁移。当前没有附件自动回收机制；附件写成功但后续消息提交失败可能留下孤立文件。优先保留原文，后续另定可见清理流程。
4. 附件首次哈希、文件首次编码检查和会话索引冷读取仍完整扫描。缓存最多 128 项，以文件身份、大小、修改时间失效；不宣称可识别恶意恢复修改时间且保持大小的内容替换。
5. grep 的 Go 回退不再静默跳过大于 1 MiB 的文件，但仍整文件读取、分割文本；没有实现流式正则引擎。已有 ripgrep 是首选。匹配数量上限保留。
6. GBK 按返回的字节游标继续读取；任意人为指定的中间字节位置不具备可靠字符边界识别。按行跳转仍需扫描此前文本，没有稀疏行索引。
7. 持续增长的任务输出会使编码缓存失效，可能重新扫描；既有输出采集容量限制未由本轮取消。大内容落盘不等于所有工具均无限采集。
8. 前端附件展开、增量加载、错误恢复提示尚未实现或验收；用户既有 GUI 工作保持原样。
9. 当前源码未提交，包含先前配置/会话隔离修改；本轮不将未连接的 fsDirs 草稿或 GUI 工作计入完成项。

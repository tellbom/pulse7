# pulse7 界面设计规范（design tokens 约束）

> 检索来源共识（2026-09）：固定字阶+token 化（避免随机字号）、正文行高 1.5-1.65、清晰 transcript 层级、单一交互主色。
> 本规范约束后续所有前端改动（人改或 LLM 生成均以此为准，防止幻觉样式）。硬底线沿用 UI 设计任务书：微软雅黑/Consolas、颜色承担状态、值班台风格、无装饰渐变（球体图标除外）。

## 字阶（固定六档，禁止出现档外字号）
| token | 值 | 用途 |
|---|---|---|
| --fs-xs | 11px | 微标注：状态字、时间戳、提示 |
| --fs-sm | 12px | 辅助信息：等宽参数、工具名、侧栏次级 |
| --fs-base | 13px | **界面基准**：菜单、设置、系统记录 |
| --fs-md | 15px | 对话正文：用户/助手消息 |
| --fs-lg | 18px | 弹窗标题、区块大标题 |
| --fs-xl | 26px | 空态主标题（原32偏大，压到26更合密度） |

## 字重
400 正文 / 500 强调与分组标题 / 600 标题与当前项。禁止 700+（雅黑加粗渲染糊）。

## 重点色（accent = 交互蓝）
- 唯一交互主色 `--blue600`：链接、激活 tab 下划线、当前会话左边条、可展开入口、focus 环
- 状态色不兼任装饰：蓝=运行、绿=成功、红=失败、琥珀=等待告警、灰=系统处理
- 黑色仅两处：发送按钮（主 CTA）、激活档位底色

## 层级手段（优先级从高到低）
1. 位置与留白（组间距 ≥ 2× 组内距）
2. 字号档位差
3. 字重差
4. 颜色深浅（g400 辅助 → g600 次要 → g900 主要）
5. 最后才是边框/背景块

## 密度
行高：正文 1.65 / 界面文字 1.5 / 标题 1.3。任务流垂直节奏 16px 起步。

## 机器可校验规则（供 LLM/审查）
- 任何 `font-size` 必须命中六档之一（scoped 组件内也是）
- 一个组件最多 1 个 accent 用途；新增强调先问"能不能用留白/字重替代"
- 新颜色必须挂 tokens.css 变量，禁止字面量色值进组件（状态色既有变量除外）
